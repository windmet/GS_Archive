# Producer 姓名宏：已批准规则

来源：[共享文本入口与 PR45 验收](../../../docs/PRODUCER_ADDRESSING_RUNTIME_20260929.md)。本页只记录已经批准并由当前代码执行的规则，不推断人物口癖或原游戏内部算法。

| 原文形态 | 翻译输入中的槽 | 显示语义 |
| --- | --- | --- |
| 恰好十个连续 `●` | `{{GS_ADDRESS:n:producer_name}}` | 玩家姓名 |
| 恰好四个连续 `●` 紧接 `プロデューサー` | `{{GS_ADDRESS:n:producer_name_with_p}}` | 玩家姓名加 `P` |

`n` 是同一句内从 0 起的出现顺序。槽可以随中文语序移动，但不得删改、复制或翻译。`さん`、`ちゃん` 等紧随字符仍是原文的一部分，不由槽自动添加。其他长度的黑点、单独四黑点及字面 `監督`、`師匠`、`下僕` 保持字面来源，译法由具体语境决定。

网页展示姓名是用户本机偏好，不写入译文。模型结果先作为 `draft`，由现有 `StoryTranslationDraft` 导入链恢复原始宏并核对槽类型、数量、身份与来源 hash；本页不授予任何句子的人工 `reviewed` 或 `final` 状态。
