[ニコニコ大百科の呼称表](https://dic.nicovideo.jp/id/5264624), received in

The file is **not** an approved entity-linking or Chinese naming policy. In
particular, `stable` means unique within that external table, not unique in
story dialogue. Generic forms such as オマエ and 先生, and the suspicious
みたらい / いじゅういん entries, require source-bound review. The Studio V2 build
hashes this file for provenance but does not scan dialogue or replace names
from it. Verified Producer addressing remains in
[`../verified/producer-addressing.md`](../verified/producer-addressing.md).
