## 架构决策

### 继续使用静态资料层

当前不需要先搭建传统后端数据库。浏览器需要的是版本化、可缓存、可审计的静态索引：

1. raw/masterdata 保留原始证据。
2. data pipeline 生成稳定实体、关系和资源可用性。
3. repository 按页面延迟加载索引。
4. selector 生成页面视图模型。
5. Vue 组件只负责导航、交互和展示。

只有出现用户账号、收藏同步、协作编辑或服务端全文搜索需求时，才引入在线数据库。不要为了“像完整网站”而提前复制一份难以追踪来源的数据。

### 三个明确边界

1. **资料馆 Shell**：导航、筛选、实体详情、跨资料域关联和 URL 状态。
2. **沉浸首页**：背景、角色、首页互动和高频入口，可以借鉴原游戏主界面节奏，但不复制不存在的系统按钮。
3. **剧情播放器**：继续由 compiled scenario 驱动，不与整体 UI 重构同时改写动作、镜头和状态机。

`masterdata` 决定语义与关系，`compiled scenario` 决定剧情演出，`ui_asset_catalog` 提供视觉证据。三者不能互相猜测或替代。
