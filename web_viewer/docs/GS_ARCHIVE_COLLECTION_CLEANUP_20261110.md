# 图鉴整理方案（2026-11-10）

范围：图鉴六个分类（道具 / 称号 / 货币 / 服装 / 摄影资源 / 其他语音）、它们共用的详情抽屉（`CollectionDetailPanel` → `CollectionEntryDetails` / `CurrencyDetailSections`），还有活动页和图鉴共用的报酬表 `ArchiveRewardTable`。

依据：master + #213/#214/#215 合并后的源码；手机宽度 390 的无头截图与可见文本（每个分类的列表，7 个货币详情，道具、称号、服装各抽样）；K60 Ultra 真机（Edge）上的活动 10020「復刻 GROWING SIGN@L -Plus 1 Good Day!-」。

## 0. 已修：累计点数表 3,000 PT 那条消不掉的绿条

- 现象：手机打开复刻活动，累计点数表 3,000 PT（报酬卡「怀抱勇气」）那一行左边有一条绿色竖线，点哪里都不消失。
- 根因：`archive-rewards.css` 给卡片类报酬行加了 `box-shadow: inset 2px 0 0 var(--gs-selected-line)`。`--gs-selected-line` 正是选中分类下划线的那种绿，所以看起来像点按后卡住的选中态。活动页本来想在 `ArchiveEventDetail.vue` 里用 `border-left: 0` 取消它，但这条覆盖是照旧版 border 样式写的，压不住现在的 box-shadow。这张表里只有这一行是卡片，所以只有它带绿条。
- 修法（本分支第一个提交）：去掉 `is-card` 类、去掉 CSS 规则和那条失效的覆盖。卡片行本身已经写着「卡片」，并且能点进卡片页，不需要额外标记。
- 验证：K60 上打开本分支，25 行报酬的 `box-shadow` 全部是 `none`，截图里 3,000 PT 那一行和别的行一样。

## 1. 共同问题：为什么会乱

1. **样式叠了三层**。基础层 `archive-domains.css`（15 处写死字号、52 处写死间距），上面是 `archive-collection.css` 和 `archive-rewards.css`，再上面是组件里的 `:deep()` 覆盖（`CollectionDetailPanel` 改标题和 meta 的字号，`ArchiveEventDetail` 又把报酬表整个重写一遍）。每改一页就往上再盖一层，同一个元素在不同页面里字号不一样。修绿条时碰到的「覆盖失效」也是这么来的。
2. **列表卡片的名字字号各不相同**（实测）：道具 12/600，服装 12/600，称号 13/600，其他语音 13，摄影资源 14/600。
3. **详情抽屉里字号太多**：抽屉标题 17、条目名 28、分区标题 20、卡片行 16/600、报酬行 14/700、正文 14、注释 12，还有 10px（低于 12px 下限）。其他语音里有 10.83px。
4. **工程语言漏到读者面前**。爬不到服务端数据，所以每一块都写了一句防御性说明。全站一共 30 多处，按出现频率排：「客户端…配置」「尚未收录」「未记录」「待确认」「资源键 / 奖励类型码 / Prefab / spine」「WorkTopView / IdolController」。

## 2. 全站规则（先定规矩，再逐块改）

### 2.1 文案规则

- **读者界面只写已知的事**。不知道的就不显示，不写「未收录」「待确认」「未记录」。空的分区整块隐藏。
- **数据边界只在一个地方说清楚**：放在图鉴页底部或「关于本站」写一次，比如「图鉴资料来自游戏客户端。商店商品、任务条件、排行榜等由服务器下发的内容不在收录范围内。」各个条目不再逐条重复。
- **出处降级**：日文原文继续放在中文下面，用小字和 `lang="ja"`，去掉「客户端文本：」这类前缀。攻略 Wiki 来源用一个小标签「攻略 Wiki」表示。
- **工程字段只给维护者看**：`原始资料` 折叠里的编号可以留，`资源键`、`奖励类型码`、`衣装 ID` 只在 `?maintainer=1` 下显示（现有的读者 / 维护者分流）。
- **禁用词清单**（加进 verifier，见 §5）：读者模板和读者数据 note 里不能出现 `客户端 服务端 配置 资源键 类型码 Prefab spine WorkTopView IdolController 未收录 待确认 未记录 占位`。`原始资料` 折叠和维护者分支除外。

### 2.2 字号与间距规则（只用 GS_UI_TOKENS）

| 位置 | 字号 / 字重 | token |
|---|---|---|
| 列表卡片名（六个分类统一） | 13 / 600 | `--gs-text-ui` |
| 列表卡片副信息、计数、徽标 | 12 / 400 | `--gs-text-meta` |
| 抽屉标题栏（「货币详情」） | 16 / 700 | `--gs-text-subtitle` |
| 条目名 | 20 / 700（手机上 28 太大） | `--gs-text-section` |
| 日文原名、注释 | 12 / 400 | `--gs-text-meta` |
| 抽屉内分区标题（用途、已知来源） | 16 / 600 | `--gs-text-subtitle` |
| 正文、列表行 | 14 / 400，行名 14 / 600 | `--gs-text-body` |
| 数量（× 30） | 16 / 600 | `--gs-text-subtitle` |

间距只用 `--gs-space-*`。分区之间统一 `--gs-space-6`，行内统一 `--gs-space-3`，列表行上下 `--gs-space-4`。

**收拢样式层**：`archive-rewards.css` 是报酬表唯一的样式来源，活动页里的 `.general-reward-section :deep(...)` 那十来条要么并进去，要么作为一个 `variant="event"` 写在报酬表自己的样式里。`CollectionDetailPanel` 里的 `:deep` 字号覆盖并回 `archive-collection.css`。`archive-domains.css` 里图鉴用到的写死值改成 token，并把这几个文件从 `design-token-baseline.json` 里降到 0。
