# 悬浮详情与窗口位移验收 · 2026-10-02

输入 HEAD：`b6c68cac`，分支 `codex/story-interaction-v2-before-b002`。用户本轮截图入口为 5198 藏品馆；Browser 使用同一工程的 5213 生产代码映射服务，不复制媒体库。

## 根因与修复

道具提示原为卡片内 `position:absolute; top:100%`。在 1280×620、觉醒与突破材料 16 件的列表中，键盘聚焦底排 FES 限定彩光碎片可复现同一提示：页面 clientWidth 1124→1109，scrollHeight 544→652，网格宽度 1076.47→1061.30px，提示越过视口底边。

现以通用 `ArchiveFloatingTooltip` Teleport 到 body，使用视口坐标固定定位。底部空间不足向上翻转，左右及上下边缘限位；监听尺寸变化重新定位，滚动、失焦、Esc、切换筛选/页码或打开详情清除提示。鼠标进入与键盘 focus-visible 共用浮层，触摸点击继续打开详情。单个共享提示替代每张卡片中的重复 DOM，保留高密网格、两行名字和等级角标。

修复后的相同场景页面 clientWidth/scrollHeight 保持 1124/544，网格宽度保持 1076.47px。底排提示完整向上显示；最右列提示 right=1272.46px，位于视口内并保留约 8px 边距。Browser 自动聚焦造成的纵向视口移动不计作本次宽度回归；记录包含原始 rect，未抹除差异。
