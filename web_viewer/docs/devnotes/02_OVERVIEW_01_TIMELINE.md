# 总论 · 第一部分：六个阶段（草稿 2026-11-03）

> 草稿。这里的日期和数字都来自 [01_TIMELINE_EVIDENCE.md](01_TIMELINE_EVIDENCE.md) 里标 ✓ 的条目，每段末尾的方括号是证据。

《偶像大师 SideM GROWING STARS》（下称 GS，昵称「果蔬」）2021-10-06 开服，2023-07-31 停服。
停服后官方在 SideM 品牌页留了剧情视频存档，但游戏里的剧情文本、卡片、歌曲和舞台不能再看了。
本站把这些内容整理成可以阅读、回看、检索的资料馆。从第一个提交到现在大约四个半月，可以分成六个阶段。

## 1. 拓荒（6 月 → 7-13）

起点是站长偶然找到的游戏 asset 包。第一版剧情播放器在本地先跑起来，6-22 才有第一个 Git 提交，当时语料已经有 5 GB，没有放进仓库。
这段时间主力是 Claude Code 接 DeepSeek API（提交里的 Claude 署名是工具写的）。7 月初做了口型和子模型嘴型，7-03 让 Masterdata 接进导航。
7-13 定下方向：做资料库和回放器，不复刻客户端，也不做抽卡。

[`ca3a28e1`；`23dbba83`、`1800c7bd`；`e43ebecb`；`SEKAI_VIEWER_DIRECTION_GUIDANCE_20260713.md`]

## 2. 治理（7-14 → 8-12）

7-14 建立 GitHub 仓库 `windmet/GS_Archive`，当天 36 个提交。之后主力换成 Codex / ChatGPT，工作方式也变了：按 PR 合并，先定契约再改代码。
PR #1（88 个提交）把剧情运行时重构并定了本地化契约；PR #2（83 个提交）把资源来源迁到 RAW 和 Masterdata，不再靠文件名和正则猜分类。
PR #3–#42 补上关系目录、发布账本和门禁。

[`gh pr view 1`、`gh pr view 2`；分支 `codex/*`]

9-08 的架构审计记录 `App.vue` 已经有 2,986 行。之后一周每天几十个提交（9-08 有 67 个，9-13 有 60 个，那天是 SideM 11th LIVE DAY2）。

9-23 PR #43 合并，264 个提交，资料馆、剧情运行时和移动端交互在这里收口。

## 6. 门户与原生复原双线（10-20 → 至今）

10-20 当天合并了 10 个 PR，包括视觉收敛（#56）、导航命名（#61）和多个 worktree 共用语料（#63）。
之后分成两条线并行：

- **门户**：10-27 起按节目册 2.0 改造门户（P0–P7）。
- **原生复原**：剧情演出、舞台和特效改为读取客户端自己的数据和几何，不再用经验参数。现有规模：
