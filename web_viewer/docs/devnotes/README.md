# 开发文档草稿区

这里是开发文档站的草稿。定稿后搬到独立的文档站仓库，这里只留链接。流程见 [00_WRITING_PROCESS.md](00_WRITING_PROCESS.md)。

分工：骨架、技术事实和出处由 AI 核对整理；正文由站长自己写，或者借助外部工具来写。
骨架里的标记：

- **【站长撰写】**：站长要自己写的段落，下面附了提示和可用素材。
- **事实**：已经核对过的条目，每条都写了出处。写正文时可以直接用，数字要照原口径写。
- **待核**：还没确认的，发布前要解决。
