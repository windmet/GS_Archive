# 门户与设计系统（骨架）

**论点**：把资料馆排成一本演出手册：内容是主角，界面退到纸面上。视觉规则写成设计令牌，再用验证脚本守住。

## 事实

- 10-03 设计令牌第一次进入代码，`src/styles/GS_UI_TOKENS.css`。〔`9431ab99`〕
- 10-05 视觉语言生效。方向是「把资料馆排成一本演出手册」，三条原则〔`GS_UI_CONSTITUTION.md`「视觉语言」〕：
  1. 内容先于容器：白底、边框、阴影只给真正浮起来的东西。
  2. 一处亮色：薄荷色只标记「现在」（选中、播放中、焦点、进度）；偶像色只出现在关于这位偶像的内容里。
  3. 结构就是信息：编号、徽章、标签必须有真实含义，不用装饰性英文眉标、统计方块和盒中盒。
- 令牌只能变好：`scripts/verify-design-tokens.mjs` 不允许新增十六进制颜色、裸字号、裸圆角和不在档位上的断点。
- 10-20 视觉收敛（PR #56）、导航命名（#61）。
- 10-27 起按节目册 2.0 改造门户，分 P0–P7 阶段，进度只看一张表。〔`PORTAL_REDESIGN_PROGRESS_20261027.md`〕
- 启动 JS 预算是 210 KiB（215,040 gzip 字节）。〔`CURRENT_STATE.md`；`379ec5cf`〕
- ⓘ 说明气泡只由 `GsInfo` 放置，页面不能自己写气泡样式。
- 加载控件统一成三档：幕布（48px，右下角）、换页卡（22px，居中）、就地（16px）。〔`GS_LOADING_SYSTEM_20261103.md`，分支 `portal/20261103-loading-unify`，**未合并**〕
