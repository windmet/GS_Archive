# 小人舞台与谱面（骨架）

**论点**：舞台和谱面原本都打算「差不多就行」；10 月中改成逐条对照客户端的指令和参数，并把还没对上的部分列成表。

## 事实

### 舞台

- 2D 小人舞台的接线主力是 ChatGPT 6.1 Sol（经 Codex）。〔站长自述，C 级〕
- 7-14 的 `DO_NOT_REOPEN.md` 写的是「纯前端不追求完美复刻 Unity 粒子」；10-13 起改为按客户端方法逐项接线。〔`DO_NOT_REOPEN.md` §3；`NATIVE_CHIBI_WIRING_AUDIT_20261013.md`（`a56e3242`）〕
- RAW 舞台指令：60 个 bundle、118 份编排、58 类、261,812 行。其中 1 行不是时序指令；行数不等于执行数，也不是完成率。〔`STAGE_RAW_COMMAND_MATRIX_BATCH_20261015.md`；10-20 `STAGE_FOLLOWUP_20261020.md` 复核〕
- 粒子：82 组模型、724 个系统、95 张纹理，其中 32 个系统还是 partial。〔`NATIVE_REHOBE_SMOKE_20261020.md`〕
- 衣装：549 个 Live 模型按适用范围、款式、版本、个人分层，套服可以按成员搭配。〔PR #103；`STAGE_COSTUME_FAMILIES_20261025.md`〕
- 加载：编舞改成按编排分片后，默认曲 DRIVE 固定读取序列的原始 JSON 从 43.58 MB 降到 22.86 MB；应援棒和 emitter 再按曲目分片后降到 1.79 MB（少了 95.9%）。
  **口径**：这是原始 JSON 读取字节，不是网络传输量，也不是开播时间；同一生产构建、限速、冷缓存的对比还没做。〔`STAGE_LOAD_STRATEGY_20261020.md`；`STAGE_STATUS_AUDIT_20261020.md`〕

### 谱面

- 10-24 原生投影、长条与 flick 提示，60Hz 播放更新隔离。〔PR #98〕
- 10-27 Auto 演示、命中特效、Combo / 315、可选打击音。〔PR #100〕
- 还没做：输入判定、完整的原机粒子 / GPU 等价、共享 hold 循环和 Special 等音效 cue、真机验收。〔`CURRENT_STATE.md`〕
