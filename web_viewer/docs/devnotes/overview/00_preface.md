# 序：为什么做这个站（骨架）

**论点**：GS 停服后，官方只留下了剧情视频存档；剧情文本、卡片、歌曲和舞台都没法再看了。本站要把这些整理成能读、能回看、能检索的资料馆。

## 事实

- GS 2021-10-06 开服，2023-04-04 公布停服，2023-07-31 停服。
- 2023-09 官方在 SideM 品牌页公开了剧情视频存档，现在是「サイスタ アーカイブ」栏目。
- 本站现在有的内容：剧情阅读与回放、通信与电话、卡片、歌曲与谱面、活动与卡池、2D 小人舞台、摄影工作台。
- 2026-09-13 11th STAGE DAY2 公布了 Switch 2 / Switch 新作。

出处见 [01_TIMELINE_EVIDENCE.md](../01_TIMELINE_EVIDENCE.md) 外部时间点一节。
