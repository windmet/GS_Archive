# 决策登记册

每条写：当时怎么做 → 改成什么 → 为什么 → 现在的规则 → 证据。只登记改了方向、以后可能有人想改回去的决定。
新增一条时按日期插入，编号不重排。

## D01 · 做资料库和回放器，不复刻客户端（2026-07-13）

- **改成**：做资料库与回放器；不复刻客户端，也不做抽卡。
- **现在的规则**：新功能先问「是在整理和回看已有内容吗」。
- **证据**：`notes/04_refactor/SEKAI_VIEWER_DIRECTION_GUIDANCE_20260713.md`（7-14 提交）。

## D02 · 资源来源从整理者导出改成 RAW 与 Masterdata（2026-07-23 → 07-29）

- **当时**：资源和关系来自整理者导出的文件。
- **改成**：RAW 提供物理载荷，Masterdata 提供语义身份；整理者导出只做对照。
- **为什么**：【站长撰写】（PR #2 只写了做了什么，没写动机）。
- **现在的规则**：组件里不许猜关系，一律经 `archiveSelectors.js` 从生成的索引组装。
- **证据**：PR #2（83 个提交，说明原文：「from organizer-created exports to the authoritative RAW + masterdata chain」）；`PROJECT_MAP.md` §3。
- **注意**：AI 稿和旧大纲里的「正则猜分类 → Masterdata」在 PR #2 里找不到依据，别这么写，除非找到别的出处。

## D04 · 电话界面改回原版（2026-09-20）

## D07 · 舞台和剧情从调参数改成读原生数据（2026-10-13 起）

- **当时**：7-14 定的是「纯前端不追求完美复刻 Unity 粒子，可禁用、可静态替代」。
- **改成**：按客户端的方法和参数逐项接线，没对上的列成 partial / 待办。
- **为什么**：经验参数怎么调都差一点，而且没法说明差在哪。
- **现在的规则**：原生值优先；估计值要标明是估计。
- **证据**：`DO_NOT_REOPEN.md` §3；`NATIVE_CHIBI_WIRING_AUDIT_20261013.md`（`a56e3242`）；`e7aab177`（10-15 ADV 按原生规则放置）。

## D08 · 大分支改成短分支（2026-10-14）

- **当时**：一个分支积几十到几百个提交（PR #43 264 个，PR #48 108 个）。
- **改成**：每件事一个按领域命名的短分支和 PR。
- **证据**：PR #48 之后的合并记录。

## D09 · 翻译身份改成按原文哈希（2026-10-15）

- **当时**：通用文本按批次管理，有整批哈希、批准绑定和修订链。
- **改成**：翻译记忆，一条原文一条记忆，键是原文 SHA-256；改动记录交给 Git。
- **为什么**：新增卡片、复用同一句、重新提取导致顺序变化时，不应影响已有译文。
- **证据**：`GS_ARCHIVE_GENERAL_TRANSLATION_WORKFLOW.md`。
