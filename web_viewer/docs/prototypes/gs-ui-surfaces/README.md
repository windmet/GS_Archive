# GS 藏品详情密度原型

直接打开 `index.html`，无需服务器、依赖或网络请求。默认展示同一条长姓名称号，默认编号 1 是 picker 的固定兜底规则。2026-10-03 用户已明确选择 Compact；生产 Dialog M 迁移另批验收，原型不会导入 App。

| Variant | 比较轴 | 适用场景 | 代价 |
| --- | --- | --- | --- |
| Compact | 元数据优先；两栏键值与紧凑来源账目 | 快速核对编号、配置期与奖励条件 | 长名称与多行说明的阅读节奏更紧 |
| Balanced | 身份和说明在前；资料侧栏；来源卡片分区 | 一般浏览与来源核对 | 同屏来源数量较少 |
| Reading-heavy | 单栏正文；原文并读；资料与来源随后 | 对照较长说明、译文和原文 | 需要更多纵向滚动 |

数字键 `1–3`、左右箭头切换；`R` 重新挂载当前版本。输入框、选择框、可编辑内容或修饰键下不触发 picker 快捷键。`?v=2` 可恢复当前版本。picker 原样来自 `prototype/PICKER.md`，仅名字与数量改变；手机详情占用底部，因此使用文档允许的 `data-position="top"`。版本切换无过渡，picker 高亮保留规定的滑动反馈。 固定 picker 工具栏保留技能原样 28px 按钮，是本原型触摸目标的明确例外。

三种方案共用生产 Dialog M 的 580px 桌面外宽。原型之间使用相同高度约束：桌面 `calc(100dvh - 112px)`、手机 `calc(100dvh - 96px)`，为顶部 picker 留出空间；这与生产的84/78dvh并不相同。比较轴为信息密度、组织和字号。详情关闭按钮在桌面与手机均至少 44px；手机或 coarse pointer 下普通按钮、搜索清空与折叠 summary 至少 44px，清空按钮宽度至少 44px。目录 hover 只作用于支持 hover 的 fine pointer，触摸仍保留 active 反馈。

目录中搜索中文／原文／说明／编号，切换道具／称号，清空查询，打开条目；关闭、Escape、点击遮罩均恢复打开控件焦点。目录在详情打开时 inert；Tab 循环覆盖详情与 picker（picker 是用于比较的独立工具栏）。原始资料、来源记录可折叠；获取方式筛选会更新实际静态来源样本。详情语言切换使用现有中文译文或原文回退。没有虚构的活动跳转、未实现的下载按钮或生产路由。

静态样本取自本地 `item_catalog.json`、`honor_catalog.json`、对应 `entity_sources`、`config/collection-browse.v1.json` 以及 `archive-general/items.json` / `honors.json`。完整输入路径与 SHA-256 在 `data-receipt.json`。

`build-prototype.py` 可从同一输入重新生成单文件 HTML 与数据收据；仅写本目录。`index.template.html` 是源模板，`index.html` 是交付物。生产代码不导入此目录。
