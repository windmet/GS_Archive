# 手机剧情沉浸观看

基线：`codex/runtime-audit-closeout` 的 `e7d5916`。实现分支：`codex/mobile-story-immersive`。

## 实施范围与取舍

- 只对所选播放范围包含 ADV 的完整剧情提供横屏入口；语音预览及纯电话、短信不弹推荐。混合剧情进入通信段时保留观看状态与原组件。
- 手机竖屏首次进入推荐横屏，可继续当前方向，可记住选择。未记住的询问在同一次页面会话内也只出现一次。菜单可修改偏好。
- 保存“优先横屏”后提供轻量点击入口，不在异步加载结束时自动请求全屏。[Fullscreen API 要求用户激活](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)；[方向锁支持有限](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)。全屏被拒绝或方向锁不可用仅提示手动旋转，不作为播放失败。
- 沉浸状态独立于隐藏界面。短横屏保留返回、菜单、对白和播放控制；语言切换也可在菜单操作。控制目标至少 44 CSS px，缩减顶部及底部预留。
- 保持 StoryStageFraming、人物坐标及原电话边框/图片比例，不新增手机三人倍率。横向空间改善的是站位可读性，不声称修复全部竖屏构图。
- 不在章节重新挂载后强留全屏：当前播放器按播放实例重新挂载，跨实例保留需要额外的全屏所有权设计。此轮先保证退出、返回及未完成请求的清理，后续章节提供手动入口。
- 不引入全站强制横屏、PWA 或原生方向兜底，不重做电话/短信视觉。

## 验证记录

使用现有本地服务 5175 与 Browser 插件。

| 场景 | 观察结果 |
| --- | --- |
| 390×844 完整剧情 | 推荐弹窗、可选择继续，背景播放暂停；保存横屏后再次进入无重复弹窗，仅保留入口 |
| 844×390 GS 运命光年 `1_3_30018_01.json`，at_step=9 | 三人可辨；沉浸时仅保留顶栏返回/菜单，正文和控制仍在；按钮尺寸约 44px |
| 932×430 同场景 | 横屏三人站位、对白与底部控制可见 |
| 1280×800 同场景 | 不自动推荐，完整顶栏，原桌面构图可见 |
| GS 电话 at_step=114，短信 at_step=280 | 沉浸中通信内容与回复按钮可见，点击回复可推进 |
| 独立电话 `040ren_303_2_3_040_03_09_a.json` | 390×844 无横屏推荐，保留原手机外框、背景比例 |
| Reader `1_2_002_02_a` → 完整剧情 → 返回 | 全屏退出后回到同一原文阅读页；再次播放无重复询问 |
| 退出 | 菜单退出、播放器 Escape 恢复完整顶栏；返回资料馆正常 |

Browser 中全屏请求成功，方向锁降级为旋转提示。内嵌浏览器在全屏叠加 viewport 模拟时截图会出现画面缩小及黑色空余区域；非全屏截图与 DOM 尺寸另行核对。本轮不是 Android/iOS 真机方向锁或浏览器地址栏收起的最终验收，仍需设备验证。

自动回归：`npm run verify:player-immersive` 覆盖同步手势、拒绝/缺失 API、系统退出、请求未完成时卸载、迟到锁定、外部全屏保护、偏好及一次性推荐。另通过 localization-runtime、runtime-foundation、communication-presentation、stage-resize 回归。`npm run build:check` 只编译代码，未复制 public 媒体库。

控制台仍存在原有 Pixi/Spine warning，本轮没有改相关依赖，不声明零警告。构建仍有大 chunk 提示。没有执行发布打包、云资源上传、长时间音频 soak 或全库 SSR 验收。
