# 视觉收敛：盘点与第一批（2026-10-20）

Portal 线本轮做视觉收敛，不重新设计。目标是让从卡片跳到歌曲、再到故事或摄影台时看不出换了一套前端。规则仍以 [GS_UI_CONSTITUTION.md](GS_UI_CONSTITUTION.md) 为准，本页只记录盘点方法、发现和分批进度。

## 盘点方法

- `node scripts/capture-gallery.mjs <标签> --base=<dev> --styles`：在原有三档截图之外，按角色采集每个可见控件的计算样式（按钮、图标按钮、标签页、搜索框、输入框、下拉框、h1–h3、对话框），按「高度 | 字号 | 字重 | 圆角 | 底色 | 字色 | 描边 | 内边距」签名聚类，写入 `.analysis/gallery/<标签>/styles.json`。同一角色出现多个签名，就是同一种控件在不同页面画得不一样。
- 基线：master `5aab5644`，本地读模型 `rm-visual-20261020`（data `fda1a54c`），29 个场景 × 3 档 = 87 张，全部干净。标签 `20261020-before`。
- 画廊的 `seasonal` 场景原来按旧 props 挂载，组件改成读模型的 `page.ledger` 后一直失败；现在由 `qa/gallery/prepare.mjs` 用读模型同一个 `buildSeasonalLedger` 生成。

## 发现（master 基线）

| 角色 | 签名数 | 主要问题 |
|---|---|---|
| 搜索框 | 7 | 5 个目录页 4 种做法：门户/歌曲是无框输入、活动/藏品带框；高度 34/36/38/42/44；藏品字重 600。门户搜索在手机上仍是 13px（宪章要求触摸输入 ≥16px，否则 iOS 聚焦会放大页面） |
| 下拉框 | 13 | 高度 32/34/36/39/40；字重 400/600 混用；卡片页偶像选择框 10.72px、5px 圆角、私有灰阶；门户语言下拉在手机上 12px |
| 章节标题 h3 | 5 | 卡片/歌曲/卡池/偶像/组合用 20/700，故事/门户/活动用 20/600；歌曲页「歌曲播放」「演唱试听」是浏览器默认 18.72px |
| 页面标题 h2 | 11 | 详情 28/700（手机 20/700），门户与故事目录 20/600（手机 16/600） |
| 文字按钮 | 190 | 大部分是合理的语境差异（侧栏、返回、筛选片），需按角色再细分后才能判断 |
| 令牌棘轮 | — | 硬编码色 455、裸字号 279（65 个 <12px）、非角色圆角 192、三档外断点 51；沉浸式组件（舞台、Spine、ADV、手机通信、Reader 主题）占前十中的一半 |

两处标题/输入框失效的根因相同：父组件的 scoped 样式只作用到子组件根元素，伸不进子组件内部，也管不到插槽传入的内容。迁移时遇到「父组件定义、子组件使用」的类名要用 `:deep()` / `:slotted()`。

## 第一批（已完成）

只修违反宪章的明确问题，不改风格取向：

- `ArchiveIdolSwitcher`：整套改用令牌（36px 高、field 圆角、line 描边、ui 字号、meta 标签、mint 焦点环）；删除未被使用的 `dark` 变体；断点 560 → 760 档。卡片页与偶像页共用。
- 歌曲页：`.song-block-heading h3` 与 `.song-block-note` 改为 `:deep()`，两个播放器组件的标题与说明回到章节角色（20/700 + rule）。
- 门户搜索与语言下拉：手机档 16px；语言下拉桌面字号改用 `--gs-text-meta`。
- 结果（标签 `20261020-batch1`，8 个场景 24 张全部干净）：卡片页偶像选择框 36px/13px（手机 44px/16px），「歌曲播放」20/700，门户输入框与语言下拉手机 16px。令牌基线：硬编码色 455 → 441，裸字号 279 → 276，圆角 192 → 190，断点 51 → 50。启动 JS 204,661 / 204,800。

## 用户选择（2026-10-20）

搜索框统一为带框；章节标题统一 700；页面标题保留详情（28/700，手机 20）与目录（20/600，手机 16）两个角色。

普查更正：第一版普查量的是输入框本身，歌曲等页面的边框画在外层 `label` 上，被误记为「无框」。普查已改为在输入框无边框时取外层带边框的盒子（标签 `20261020-census2`）。实际上所有目录搜索框本来都带框，差异在高度、圆角、内边距和字重。

## 第二批（已完成）

- 目录搜索 / 筛选输入框：桌面 36px（`--gs-control-normal`）、13px / 400、field 圆角、`--gs-space-4` 内边距；手机与粗指针 44px / 16px。改动：歌曲（圆角 6 → 令牌）、藏品（桌面 44 → 36，去掉继承来的 600 字重）、摄影目录（桌面 44 → 36）、`ArchiveListHeader` 的筛选框（`:slotted` 让插槽传入的输入框也套上，`box-sizing` 修正 38 → 36）。
- 门户全站搜索保留 44px，作为首页主入口规格；引导对话框里的表单字段属于对话框，不在此列。
- 章节标题 700：活动详情、通信、门户分区、故事页章节头。故事卡标题、抽屉年份、设置面板标题是其他角色，未改。
- 结果（标签 `20261020-batch2`，86/87，唯一失败是 player 平板档在 swiftshader 下超时的已知问题）：搜索框签名 8 → 6（剩余差异只是外层图标颜色），输入框 5 → 4，h2 11 → 10。令牌基线：裸字号 276 → 275，圆角 190 → 188。启动 JS 204,664 / 204,800。

## 第三批（已完成）

- 下拉框：标准为 36px（手机 44px / 16px）、13px / 400、field 圆角、12px 左内边距。偶像页与活动详情去掉 600 字重；活动详情原来用竖向内边距撑到 39px，改为 `min-height` + `box-sizing`；偶像选择框左内边距 8 → 12。卡片列表筛选和技能 Lv 下拉保留 compact 32px：它们和同一行约 30px 的稀有度筛选片、布局切换配套，属于宪章允许的 compact 档。顶栏语言下拉是无框的外壳控件，另成一类。
- 筛选片：32px 胶囊、12px 内边距、未选 400、选中 600（`--gs-selected-*`）；手机与粗指针 44px。改动：歌曲、藏品（原 600 / 11px）、摄影目录（桌面 44 → 32）、卡池（选中加 600）。
- 结果（标签 `20261020-batch3`，87/87）：下拉框只剩标准 / compact / 语言三类；五个目录页筛选片完全一致。令牌基线圆角 188 → 186。启动 JS 204,662 / 204,800。

## 下一批
