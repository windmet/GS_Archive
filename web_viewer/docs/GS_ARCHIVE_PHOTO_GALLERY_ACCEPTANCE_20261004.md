# 摄影资料画廊验收

输入基线：`0134512e`，分支 `codex/chibi-stage-reconstruction-20261002`。本批仅改摄影目录、详情弹窗、App 的明确关闭接线及对应回归；不改摄影工作台渲染器。

## 设计与真实数据

| Before | After | Why |
| --- | --- | --- |
| 左侧单列目录、右侧常驻预览 | 通栏响应式网格，点击打开原生详情弹窗 | 同时浏览更多素材，按需查看详情 |
| 不同尺寸素材使用相同列表 | 地点／场景横版；表情、动作、贴纸与相框紧凑网格 | 保留背景细节与透明素材的真实比例 |
| 场景只按自身名称搜索 | 同时搜索真实关联的父地点原文及译名 | 可以通过“摄影棚”找到相关场景 |
| 详情长期占据主页面 | 明确选择才打开；关闭清除 URL 的 photo 身份 | 分类／偶像切换不自动弹出详情 |

地点 133、场景 186、贴纸 184、相框 26、滤镜 4，均来自正式读取模型。表情／动作按偶像读取。没有虚构室内／户外、活动／常驻分类；动作当前展示实际静态缩略图，未伪称动态重建。滤镜明确说明网页近似效果，未声称已解析原始参数。

贴纸详情优先绑定完整贴图；相框原始前后图层分别显示。背景图片用 contain 保留完整画幅。来源详情默认收起。
