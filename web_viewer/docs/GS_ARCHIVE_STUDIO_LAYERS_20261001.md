# 摄影工作台图层与删除操作验收

2026-10-01；输入 HEAD `0e14af02`，分支 `codex/story-interaction-v2-before-b002`。谱面/实验室批次已经提交并推送，本批响应用户追加的摄影图层、默认冬马删除、按钮提示及移除动作秒/表情秒请求。

## 改动

- 原「对象」菜单改为明确的「图层」入口，显示可编辑图层数量。桌面首次打开图层侧栏，画布为侧栏留出空间；手机按需打开面板。
- 图层列表不再因默认人物已选中而折叠。各组按前到后排列，贴纸前景/人物分别排序；背景和画框使用如实的不可移动提示，没有伪造跨组混排能力。
- 选中层有边线、高亮、类型和可读名称；同组有顺序编号。手机选中层的名称单独占一行，排序/删除操作放在下一行，其他层保持紧凑。
- 画布上方常驻缩小、放大、带文字的「删除」「撤销」。默认冬马可直接删除，空构图有添加提示。删除后选择同组相邻层，撤销恢复原图层、原顺序和属性，不回退其他对象之后的修改。
- 撤销范围是最近一次删除；载入另一构图后不能跨文档恢复旧图层，也不突破 6 人/32 贴纸上限。并非通用撤销/重做历史。
- 保存/导出与全屏集中到独立入口。按钮加图标、title 和可访问名称，危险操作区分颜色，禁用状态明确。320px 顶栏保存入口位于约 312px 内，无页面水平溢出。
- 动作和表情用来源绑定的中性编号代替内部动作/资源名，原始预设证据仍在折叠区。按用户最新要求删除「动作秒」「表情秒」两个输入；既有 StudioDocument v2 定格数据和文件兼容性保留。
