## 四个重点的具体边界

### 蝶蝶桑：需要同时收束两种旧译

40条均为猫柳对华村翔真的固定称呼，不能只搜“蝶蝶小姐”：主线、组合／偶像剧情里还存在12条“蝴蝶先生”。原文为 `ちょうちょさん`，`さん`本身没有要求译成小姐或先生；采用“桑”可保留这项称呼而不附加该选择。这里是项目风格方案，不宣称存在官方中文定译。

例如主线 `1_4_002_05_i`：

> くろークン、ちょうちょさん！
>
> 现译：九郎君、蝴蝶先生！

建议为“九郎君、蝶蝶桑！”。猫柳另一句 `蝶々みたいにひらりひらり…` 是“如蝴蝶般”的比喻，不应改成专名。

### 矮子：限涟→武，不等同全局チビ

64条包含当面叫喊、内心独白、聊天和涟的通信签名；当前全部为“小不点”。“矮子”更明确保留针对身高的贬称色彩，符合用户想调整的方向。

反例必须隔离：玄武说福利院里的孩子 `施設にはチビもいるし`，当前“小娃娃”；志狼对花音说 `かのんだってチビだけど`，当前“小不点”。两者不属于涟对武的绰号。

### 蛙埃尔：专名与物种须分开

用户观察到的问题属实，但并非完全统一为青蛙：2022情人节剧情 `5_01_010_22_b` 的两条已使用“蛙埃尔”。其余31条则是27条“青蛙玩偶”，以及青蛙／青蛙君／青蛙酱。

最清楚的命名句是皮埃尔N卡普通台词：

> こっちはカエール。ケロッケロー！
>
> 现译：这是青蛙玩偶。呱呱呱！

此处可用“这位是蛙埃尔”。但天道辉看到的大青蛙、花毛茛词源中的普通青蛙、`カエルの国`／青蛙王国，以及不知名字的小女孩称皮埃尔玩偶服为 `カエルさん`，不能跟着替换。后者即便指向相同角色，也只是路人的泛称，不是已说出了カエール这个名字。

### Papi：需要恢复已经消失的词根

不只是“啪噼→Papi”：41条已译成元气满满、超绝可爱、开心满满、幸福咲、干脆利落，或未保留词根。仅替换汉字会漏掉大半问题。88条还包括阿斯兰的 `パピ族`、神谷引用咲的话、制作人的四个回复字段、道具文案及三个季节标题。

关键上下文：咲问“Papi可爱和Papi酷炫选哪个”，制作人两个短选项与两个详细回复必须一起处理；组合前传中阿斯兰还有 `（パピ……？　異国の言葉か？）`，因此前文若将词根全部意译，后句对这个词的疑问就失去对应。

建议讨论以下词族表；这是方案，尚未回填：

| 日文 | 建议方案 | 仍需统一的细节 |
| --- | --- | --- |
| パピ／パピッ／パピっと | Papi | 按中文句子调整助词，不机械在每处补“地”。 |
| パピパピ／パピパピッ | Papi Papi | 保留重复；不能压成一次。 |
| パピプペッ | PapiPuPe | 保留追加音节；最终大小写可由项目统一。 |
| ハピパピ | HapiPapi | 现有Happy Pappy和“幸福咲”都另列讨论。 |
| パピカワ／パピかわ | Papi可爱，或PapiKawa | 前者中文可理解，后者完整保留造词；现有一条已注PapiKawa。 |
| パピクール | Papi酷炫，或PapiCool | 应与PapiKawa采用同一体例。 |
| パピキラ | Papi闪亮，或PapiKira | 不能只改成普通的“超级闪亮”。 |
| パピ族 | Papi族 | 收束现有帕皮族／帕比族／啪噼族。 |

中文社区采用Papi并非凭空推断：[萌娘百科水岛咲](https://moegirl.icu/%E6%B0%B4%E5%B2%9B%E5%92%B2)有Papi、Papi族和Roll用法。本轮只把它作为社区写法证据，不将其当作官方中文政策，也不据此改写整个角色的人设。[皮埃尔条目](https://moegirl.icu/zh-tw/%E7%9A%AE%E5%9F%83%E5%B0%94)区分普通青蛙与名为カエール的玩偶，但该页没有直接为“蛙埃尔”提供官方定译；本项目已有的两条用例和用户偏好才是采用这个汉译的依据。

## 扩展发现中优先核对的两处

**犬名→乐器。** 丽的工作剧情 `1_5_008rei_1_5_008_04`，unit `cmd-000026:dialogue:000`：

> アルトというゴールデンレトリバーを飼っている。
>
> 现译：养了一只叫中提琴的金毛寻回犬。

前后都是谈大型犬，应沿用此前项目确认的“阿尔托”；这是明确的实体名误解，不只是选哪个音译的问题。

**昵称→食物。** 庄一郎生日剧情 `1_2_028_02_b`，unit `cmd-000092:dialogue:000`，咲说：

> ケーキといえば、やっぱりロールだよね！
> もう何か浮かんでたりするんじゃない？
>
> 现译：说到蛋糕，那果然是蛋糕卷了吧！
> 卷绪已经有什么想法了吗？

下一句由卷绪回应“嗯，不过还是大家一起想吧”。因此这里是在叫ロール，即卷绪的昵称；建议为“说到蛋糕，果然还得是卷卷！你是不是已经有什么点子了？”。至于是否全站改用Roll，可作为另一项风格决定，不能把普通的ロールケーキ／蛋糕卷、コントロール／控制也一起替换。

## 其余四组为什么值得一起讨论

- **涟→道流：** 当前36条涉及该关系的らーめん屋，既有“卖拉面的”，也有“拉面店的”“拉面店老板”“拉面屋”，甚至“狡猾的拉面店！”这种把人说成店铺的句子。建议与“矮子”一并敲定语气。但 `らーめん屋ん家`要表达道流家，不能统一成去拉面店。
- **组合名：** もふもふえん的49条保留原名，四个元数据字段却是毛茸茸园／萌萌组合。它们是组合专名，应优先于普通“毛茸茸”的描述处理。
- **大吾→制作人：** 146条里Boss／老大／老板混用。这不一定单句都错，但影响固定称呼一致性。涉及 `●●●●●●●●●●ボス` 等受保护称呼时，须沿共用称呼机制改动，不能直接替换宏内部字符。
- **猫柳自称：** 742条猫柳发言中仍有23条“在下”，分布于主线、活动、季节、卡片通讯与聊天。155条相关对照中还收录原文有ワガハイ而中文用我们、咱或自然省略的情况；后者需要句法判断，不应再次用代词数量机械对齐，也不应删除原文省略主语时自然出现的“吾辈”。
