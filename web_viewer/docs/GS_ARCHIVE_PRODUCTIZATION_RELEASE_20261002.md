# 资料馆产品化与增量发布核验

本轮承接元数据中文草稿、门户引导、摄影编辑体验与 Reader/Player 语言衔接。乐曲、谱面代码按用户要求冻结；资源清单仅纳入其已经存在的新增文件。

## 图片与目录

原始 PNG 的发布转换继续使用无损 WebP：保留尺寸及所有可见像素，只将 alpha=0 的 RGB 清零，保留部分透明像素。原始资源不覆盖。壁纸是已有的响应式衍生图，沿用原先的最大宽度 720/1600 和缩略图 160/240；这次将其原有有损编码改为 lossless/exact。248 张壁纸、139 张场景缩略图，共 883 文件、486029946 B。53 个不满足原有不透明背景条件的条目仍排除，没有扩大资源可用性声明。

当前源依赖清单：103229 文件、11464558337 B，10416 个剧情资源计划；82 个历史缺失引用继续显式保留。只收录当前壁纸菜单引用的内容寻址衍生图，旧本地文件保留，不重复上传。

壁纸选择器与门户署名共用源文绑定的卡名分片，中文、原文搜索均可用；搜索失败展示匹配提示，目录为空另行提示。原始菜单 label 不改写。分片只在打开壁纸选择器或恢复已选壁纸时加载。

## 发布边界

用户授权条件为实际目标桶总量严格小于 8600000000 B；等于上限也停止。容量核算包括旧版本、旧对象、新版本目录及覆盖差额，并以所有正差额计算保守峰值。账户另预留至少 880000000 B。禁止借删除远端对象获得容量许可。

`export-preview-assets --inventory` 只建立依赖清单；`prepare-preview-incremental-assets` 在 E 盘新批次目录编码/压缩并生成来源 hash。图片核验逐项比较原始 PNG 与 WebP 的尺寸和 RGBA；终端衍生图额外拒绝有损 WebP。上传工具绑定图片验收清单、重新校验来源和暂存 hash、gzip 解压 hash，并在 copy 前重新读取目标桶与其他桶容量。默认只做 plan，显式 --upload 才写远端；不执行 sync/delete。

Pages 包只带代码、readmodel、已提交翻译和既有工作回填目录，资源走 R2。固定测试分支 `gs-architecture-device-test`，不能把此批视为生产或真机验收。
