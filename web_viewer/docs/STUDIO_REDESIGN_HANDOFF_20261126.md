## 一、现状盘点：网页版已实现内容与当前痛点

网页版拆为两层页面：
1. **入口引导页 `/studio/`**（[ArchiveToolLanding.vue](../../src/components/archive/ArchiveToolLanding.vue)）
   - 现状：左侧一张静态宣传图，右侧一句简介 +「从担当开始 / 从背景开始 / （如有本地草稿）继续上次的构图」三条素文本行 + 体积提示。
   - 痛点：**信息密度极低、外观过素**，未体现工作台可调的服装/表情/动作/贴纸/相框/滤镜、图层编排或自带构图模板；高频轻量动作也未前置到入口。
2. **三栏编辑器 `/studio/edit/`**（[PictureStudio.vue](../../src/components/archive/PictureStudio.vue)、[picture-studio.css](../../src/styles/picture-studio.css)）
   - 现状：
     - 顶栏：返回 + 标题 + 撤销删除（`Undo2`） + 导出 PNG 图标 + 保存/载入/参考构图抽屉（`Save`） + `中 | 日`。
     - 左侧素材库：拍摄（地点 · 人物）| 装饰（贴纸 · 相框 · 滤镜）。
     - 中间画布：16:9 自由编排舞台 + 底栏（当前选中对象名称 / 缩小放大 / ±5°旋转 / 删除 / 预览动作 / 吸附开关 / ⓘ）。
     - 右侧检查器：上半区为「图层列表（拖拽重排 + 锁 + 显隐 + 背景层）」、下半区固定紧跟着「当前选中对象的服装/表情/动作、景别、叠放前移后移、滑块微调与预设来源」。
   - 痛点：
     - **核心高频动作藏太深**：「参考构图 A / B」藏在右上角 `Save` 抽屉里，几乎无人发现；居中对齐、旋转归零 `0°`、复制图层、背景时段切换、景别快切缺乏画布内顺手按钮。
     - **顶栏导出入口不显眼**：PNG 导出只是四个同等大小的图标按钮之一，缺乏 P 图软件明确的主操作锚点。
     - **检查器垂直拥挤**：图层列表与属性编辑器同栏堆叠，人物差分较多时需要反复上下滚动。
     - **空画布缺乏上手引导** + 右侧「预设来源」仍直接暴露 `modelId` 等工程字段（未接入 `isMaintainerMode()`）。

## 二、原版客户端（Ghidra 反编译核对）交互架构参考

源码证据位置：`E:\Tools\ghidra_work\sidem\decompiled14\`（基于 `dump.cs` 与 `PhotoStudio*.c` / `StudioRoot*.c` 反编译记录，交叉参考 [PORTAL_REDESIGN_PROGRESS_20261027.md](PORTAL_REDESIGN_PROGRESS_20261027.md)）。

### 1. 原版入口厅：`PhotoStudioTopView`
- 首页视觉核心不是静图，而是**随机展示写真背景**（`_RandomChangePhoto_` 每约 8.5 秒切换一次背景示例图），直观告诉玩家「这里能拍出什么样的照片」。
- 入口操作极简聚焦：「撮影」（进入摄影）与「アルバム」（查看相册/成品参考）。
- **新解锁提示机制**（`PhotoStudioNewSceneDialogContent` / `PhotoStudioNewSceneDialogTableView`）：进入时若检测到新获得的地点或场景，弹出按地点分组的通知卡片（地点缩略图 + 地点名 + 新场景名）。
  - **对网页版的启发**：存档站没有养成解锁，但完全可以把「推荐开拍场景 / 参考构图示例 / 本机最近草稿」以视觉缩略卡形态呈现在 `/studio/` 入口大厅，既替代素净空白感，又还原原版一进来就能看到「摄影氛围与最近新增/可拍内容」的预期。

### 2. 原版断点续作与退出确认：`PhotoEditDataResumePopupContent` & `PhotoEditDataSuspendPopupContent`
- **进入工作台时（`IsExistTempData`）**：`PhotoEditDataResumePopupContent` 提供 3 路分支按钮（从头新建 / 继续上次暂存编辑 / 取消），而不是把“继续上次”只做成一条毫无细节的文字行。
- **退出工作台时**：先从子面板退回编辑顶层状态（`Top`），触发离开时弹出 `PhotoEditDataSuspendPopupContent`（「是否保留暂存后退出」），并配 **「以后不再询问（`IS_PHOTOSTUDIO_EXIT_DO_NOT_ASK_AGAIN`）」** 勾选开关。
  - **对网页版的启发**：网页端当前仅靠用户手动点右上角保存；可参考原版增加轻量离开保护或自动暂存状态指示（`已自动暂存` / 离开前提示未保存改动），并在 `/studio/` 入口直接渲染出「上次编辑的草稿摘要卡（场景缩略图 + 人物头像列表）」。

### 3. 原版工作台状态机与操作流：`PhotoStudioView` & `PhotoStudioView.UIState`
- **子状态明确分层**：`Top` / `IdolSlotList` / `IdolSelect` / `IdolDetail` / `SpotSelect` / `Move` / `Photo`。
  - `SpotSelectPanel__SelectReload` + `OnClickBgIcon` → `StudioRoot.SetBackground`（换场景时同步切换舞台光影与背景）。
  - `IdolSlotList__GetSlots` / `IdolSelectPanel__FooterOpen` / `IdolSelectPanel__SetSlot` + `IdolSlot__get_IdolPriority`：原版以固定插槽控制多名偶像先后序。网页版保留「自由拖动 + 图层重排」这一明显更强的优势，但在入口页和素材面板顶部可以用类似**「已上场槽位头像条」**来一眼切换正在编辑哪位偶像，降低来回点选图层列表的门槛。
  - `StudioPresetPanel__LoadData` & `IsShowPreviewPanel` / `PreviewPanel__OnClickClose`：**纯净预览模式**！进入 `Photo` / 预览状态时一键隐藏所有边框、操作手柄与两侧栏，只留完整 16:9 成片预览和拍照/保存按钮（`PhotoPanel__IsSaved`）。
  - `MoveSliderPanel__SelectReset`：原版在移动缩放界面提供一键**「重置位置/参数（Reset）」**的显式按钮。网页版虽然有底部「重置对象」，但在画布选中栏旁边把「居中」「角度归零 `0°`」「复制」提前出来，正切合 P 图软件与原版顺手归位手感。
  - `StudioRoot.AddFrame` / `StudioRoot.RemoveFrame`：相框作为装饰顶层，开关成本应极低（画布底栏或预览状态也能直观确认当前叠加效果）。

## 三、结合 P 图软件习惯的 4 条网页端改造候选方向（供 `/grill-me` 决策）

1. **方向 1：把 `/studio/` 入口页升级为「开拍大厅 + 模板/选人前置」**
   - 视觉强化：主宣传图升级为**多场景/参考构图预览画廊（或可点选的参考构图 A / B 实拍缩略图）**，下挂清晰的能力徽章（自由图层 · 全部服装/表情/动作 · 贴纸/相框/滤镜 · PNG 导出）。
   - 前置开拍卡：
     - 「快速模板起手」：**单人定妆照（半身）** / **双人同框（参考 A）** / **全团大合照（参考 B）** / **从空白背景开始**；
     - 「快速带人进画布」：保留「从担当开始」，并支持旁边的担当同团/常用头像快选；
     - 「最近构图草稿」：如检测到 `localStorage` 存有构图（`sidem-studio-document-v1`），显示背景图 + 出场人物头像预览，点击直接恢复（对应原版 `ResumePopup`）。

2. **方向 2：编辑器顶栏主按钮 + 画布底栏高频小操作前置**
   - 顶栏右侧：突出主行动按钮 **`导出 PNG`**（带文字主色胶囊），旁边配短文字图标按钮（`撤销` / `保存` / `全屏`），配合更克制的 `中 | 日`。
   - 画布底栏（选中人物或贴纸时）：除现有的缩小/放大/左转/右转/删除外，前置 P 图软件最常用的顺手操作：
     - **水平居中 / 画布居中**
     - **旋转归零（`0°`）**
     - **复制图层**（`Duplicate`）
     - 选中人物时**景别胶囊（全身 / 半身 / 特写）**直接前置在底栏或悬浮条
     - 背景有多个时段（昼/夕/夜）时，在画布控制区旁放一组**时段快切微胶囊**
   - **纯享预览（还原原版 `PreviewPanel`）**：增加一键「隐去辅助框预览成片 / 拍一张」按钮，确认构图不带选中虚线，效果理想直接点击下载 PNG。

3. **方向 3：右侧检查器拆分为「编辑属性 | 图层 (N)」双签**
   - 右侧 `300px` 面板顶部改为 **`属性` | `图层 (N)`** 两个明确切换签（桌面宽屏也可保持图层区可折叠、默认收起到简洁列表或独立标签）：
     - 在「属性」签中，整块垂直空间全部让位给**服装 / 表情 / 动作网格**或背景时段控制；
     - 「预设来源」中的内部 `modelId` 与脚本校验注记收进 `v-if="maintainer"` 门禁；
     - 底部「位置与大小微调」增加常用单位标签与一键归零。

4. **方向 4：空画布 3 步轻引导 + 离开暂存保护（对照原版 `SuspendPopup`）**
   - 当 `objects.length === 0` 时，在暗色舞台中央显示一块可随时点叉或自动退场的轻量半透明浮层：**「① 在左侧选地点 → ② 点人物或贴纸加入画布 → ③ 调整服装表情并导出 PNG」**，并给出「添加担当」/「载入参考构图 A」两颗快捷按钮。
   - **退出保护**：当画布存在未手动保存的改动时，参考 `PhotoEditDataSuspendPopupContent` 给出轻量暂存/保存确认提示（附「自动暂存并离开」或「不再询问」）。

## 四、新窗口执行 `/grill-me` 时需要拍板的 5 个设计问题

1. **`/studio/` 入口风格定位**：保留轻量「静图 + 按钮 + 模板」，还是模仿原版 `PhotoStudioTopView` 做成带定时轮播实景范例的开拍大厅？预设支持哪些开拍模板（仅参考构图 A/B，还是额外补充担当同团一键开拍）？
2. **右侧检查器结构**：「编辑属性」与「图层 (N)」是做成两枚切换 Tab，还是保留同屏上下分栏但让图层列表默认折叠到 2–3 行高度？
3. **画布工具条密度**：桌面端与手机端各前置哪几个小操作（推荐必选：`居中对齐` + `旋转归零` + `复制图层` + `纯享预览`；可选：`景别快切` + `背景时段快切`）？
4. **退出保护与草稿策略**：采用静默自动保存到 `localStorage`（仅在入口提供「继续 / 新建」），还是严格还原原版 `SuspendPopup` 在点击「返回」时弹窗确认？
5. **验收重点**：手机端（`390×844`）双栏底部控制条和检查器切换，是否需要顺手重排触摸热区高度与竖屏画布占比？
