# Work strict-v2 text backfill publication

Release `2026-09-28-story-work-text-backfill-001` promotes exactly 637 Work standalone stories from the local strict-v2 candidate ledger. The prepublication baseline is commit `eb4478d5eabd26c32bc20d8bb920d5dc38c4c30f`. The source-list boundary is the 637 `domain: work` rows in the prepublication Reading manifest; every candidate is matched by scenario ID and candidate SHA-256.

The prepublication pilot verified 637/637 Reader row-kind, text and order parity, 4,103/4,103 nonempty rows with `text_ref`, and 637/637 non-text runtime projection parity after excluding expected text identity and RAW provenance. The mounted release owns 637 compiled JSON artifacts in the publication ledger and authoritative Story registry. Reading was regenerated from these sources, leaving 2,800 documents and 311 unsupported documents overall. Translation preflight now reports 5,035 of 30,104 nonempty rows with verified identity, compared with 932 before this release.

The old Work compiled files were ignored by Git. For a portable rollback, [the backup manifest](GS_WORK_TEXT_BACKFILL_BACKUP_20260928.json) records each old compiled and Reading SHA-256, and [the rollback archive](GS_WORK_TEXT_BACKFILL_ROLLBACK_20260928.zip) contains the exact 637 old compiled JSON bytes, recovered from the existing preview R2 objects and checked against the hashes recorded before replacement. The manifest pins the archive SHA-256. Old Reading and registry bytes are in the baseline Git commit; the manifest records their hashes. A rollback must be a new publication-ledger transaction, not an edit to this append-only release. Restore the archived compiled bytes and baseline Reading/registry state, regenerate derived manifests, and verify hashes before publishing that rollback.

The test-site package routes the 637 Work compiled files, their Reader documents, and the affected manifests through a bounded `/_work-backfill/` static overlay. The rest of the test site's data remains on its existing R2 snapshot. This preview overlay does not claim a new complete R2 corpus or production acceptance. The five known choice-target-invalid candidates and the missing `1_2_001_12` birthday episode remain outside this Work release.
