The prepublication baseline is commit `eb4478d5eabd26c32bc20d8bb920d5dc38c4c30f`. The old Work compiled files were ignored by Git. The manifest pins the archive SHA-256. Old Reading and registry bytes are in the baseline Git commit; the manifest records their hashes. A rollback must be a new publication-ledger transaction, not an edit to this append-only release. Restore the archived compiled bytes and baseline Reading/registry state, regenerate derived manifests, and verify hashes before publishing that rollback.
