## 1. 用户报的问题：根因和量出的数

### 1.1 侧栏标识和右侧标题不对齐

| 页面 | 品牌行底线 | 标题行底线 |
|---|---|---|
| 通信、剧情、卡片、偶像等栏目首页（标题旁有同组栏目） | 61 | **67.8** |
| 卡面、歌曲、偶像详情、图鉴各类（没有同组栏目） | 61 | 61 |

- 品牌行是固定的 `calc(60px + 1px)`。
- 标题行在桌面被改写成 `grid-template-rows: minmax(var(--archive-topbar), auto)`（`ArchiveShell.vue` `@media (min-width: 761px)` 一段），内容多高它就多高。
- 撑高它的内容：面包屑一行 13.8，加间隙 5，加同组栏目按钮 32，加上下内边距 16，再加 1px 细线。
- 详情页「对齐」只是碰巧，那些页没有 32px 的同组栏目按钮。
- 就算底线对上，标题文字的中线在 41px，品牌文字块的中线在 30.5px，读起来也不在一条线上。
- 资料馆首页自己画标题行：没有 61px 的细线，标题中线在约 46px。这一点交接第 2 节第 7 条要求统一，没做。

### 1.2 面包屑和标题挤在一起

- 字号：面包屑是 `0.72rem` = 11.52px，手机 `0.68rem` = 10.88px，都低于 12px 下限。`verify-design-tokens` 的 tiny 计数把它们当旧账记着。
- 排法：面包屑叠在标题上方，和 44px 的「返回」并排塞进一行 60px。
- 重复：
  - 面包屑最后一项就是标题，同一个名字在顶栏出现两次，页面里的幕上还有第三次（卡面、偶像、歌曲详情都是）。
  - 根「资料馆」和侧栏、品牌重复。
  - 栏目首页同时有返回、面包屑、同组栏目三种找路方式。卡片目录、LIVE 页的页内大标题又和顶栏标题重复。
- 「返回」是薄荷色，计算值 `rgb(10, 122, 91)`：
  - 顶栏把 `--archive-back-ink` 设成 `--gs-mint-ink`，`ArchiveBackAction.vue` 里还写死了 `#16838d / #cde7eb / #eaf8f6 / #168f98`。
  - 违反交接第 2 节第 1 条（返回撤掉薄荷）。
  - 手机顶栏的返回箭头也一样。
- 同组栏目：悬停用 `--gs-mint-ink`，是文字按钮，同样不该用薄荷。各栏目首页也不一致：通信旁有「剧情」，歌曲旁却没有「配乐」。

### 1.3 图鉴展开的小菜单挤，侧栏放不下

**图鉴子菜单：**
- 两列格子，每格 61px（1280 / 1418 宽）或 66px（1440 宽），12px 字，没有图标，从 36px 缩进起排。
- 「摄影资源」「其他语音」把格子塞满，两格之间只剩 8px。
- 当前项白片 32px 高，导航项是 36/40，同一个侧栏里有两种「你在这里」。

**侧栏溢出**（图鉴展开时）：

| 视口 | nav 内容高 | nav 可见高 | 溢出 |
|---|---|---|---|
| 1418×764 | 659 | 631 | 28 |
| 1280×688 | 659 | 555 | **104** |

- 根因：P1+ 在品牌行和导航之间加了担当行（52 + 12），但行高档位没跟着调。
- `ArchiveShell.vue` 里「Laptop and tablet heights: the whole sidebar, 图鉴 open, still fits without scrolling」这条注释已经不成立。
- 导航单独滚动，所以条目会滑到固定的担当行下面被硬切。用户截图里「资料馆」只露半截，就是这个原因。

**和方向稿不一致的地方：**方向稿「图鉴」一节写的是「六类共用一个页面：上面是类别标签」。实际做法是：
- 侧栏折叠格保留了。
- 把道具内部的分类（体力恢复、招募券……）做成了下划线标签。
- 做法是在 `archive-collection.css` 文件末尾追加一段「节目册 2.0 图鉴」覆盖样式，把 `.collection-chips` 改造成标签。

## 2. P1.5 外壳校正（规格）

分支 `portal/20261027-p15-shell`，在 #106、#107 合入后从 master 开。

### 2.1 标题行

- **高度**：桌面上标题行 = 品牌行 = `calc(var(--archive-topbar-row) + 1px)`，`box-sizing: border-box`，不随内容长高。
  - 删掉 `minmax(var(--archive-topbar), auto)` 那条行轨改写。
  - 删掉标题和面包屑的 `white-space: normal; overflow-wrap: anywhere` 换行规则。
  - 长标题在行内省略。
- **排法**：一行，垂直居中，依次是：
  1. 返回：36×36 图标钮。
  2. 上级面包屑：13px，ink-3，后接「/」（`--gs-rule`）。
  3. 标题：16 / 600，ink，单行省略。
  4. 右侧：搜索、中|日。
- **面包屑**：
  - 只列上级。根「资料馆」和当前项都不进面包屑，当前项就是标题。
  - Shell 渲染 `breadcrumbs.slice(1, -1)`；完整路径留给 `aria-label`。
  - 三级以上时中间项收成「…」。
- **返回**：
  - 只在栏目首页以下出现，也就是有上级面包屑的页。
  - 颜色 ink-2，悬停 `--gs-hover`，读屏名称写「返回{上级}」。
  - `ArchiveBackAction.vue` 的四个写死色值删掉，baseline 的 raw/hex 计数跟着降。
  - 手机顶栏的返回也改成 ink-2。
- **左缘**：
  - 有返回：左内边距 16。
  - 没有返回：左内边距 `--gs-gutter`（32），标题和正文左缘对齐。
- **同组栏目**：桌面删掉。组合进侧栏，见 2.2。`siblingSections`、`.archive-sibling-switch` 只在没有侧栏文字的图标栏下还有意义，可以一起删。
- **页内重复的大标题**：栏目首页删掉页内和标题行重复的大标题，例如卡片目录的「卡片」、LIVE 和摄影工作台的 h2。详情页的幕里保留名字。
- **资料馆首页**：标题行改成同一行 61px，带细线。
  - 内容：「资料馆」、「全站 | 担当」分段、搜索、中|日、两个图标钮。
  - 分段后面那个孤立的上下箭头图标删掉，换担当在侧栏的担当行。
  - 手机上搜索框和分段要占满整宽，现在只到约 80%。
- 原型实测（`shellfix.js`）：1280×688 和 1418×764 下两条底线都在 61；标题左缘在 220（侧栏 188 + 32）；卡面详情显示「← 卡片 / 映入眼帘的彼方」。

### 2.2 侧栏：208 / 58 可收起

- **宽度**：
  - 展开从 188 加到 **208**。
  - 收起成 **58** 的图标栏：58 是图标中线（距左 29px）的两倍，收起时图标、担当头像、M 标都不横移，只是文字消失。
  - 原型实测两种状态下首个图标都在 x = 20–38，头像都在 15–43。
- **开关**：
  - 放在侧栏底部一行：左边 32×32 图标钮（lucide `PanelLeftClose` / `PanelLeftOpen`，中线 29），右边「关于本站」。
  - 收起后这一行只剩图标钮。「关于本站」在资料馆首页页脚还有入口（`ArchivePortalOverview.vue` 的 `overview-footer`）。
- **收起后的内容**：
  - M 标：点了去资料馆。
  - 担当只剩头像，弹层向右展开，内容不变。
  - 每项一个图标，悬停或聚焦 300ms 后在右侧显示名字（用 `ArchiveFloatingTooltip`）。
  - 当前项还是白片，宽 42。
- **状态**：
  - 写在 localStorage 的 `sidem:archive-sidebar`，取值 `rail` / `full`，用 App.vue 已有的 `localStorageValue` / `setLocalStorageValue`。它是本机便利，不进设置备份。
  - 没选过时：1101 以上展开，761–1100 收起。
  - 横屏手机（`max-height: 500px`）仍强制图标栏，和收起共用一个 `is-rail` 类，不再维护两套。
  - 收起后，现在图标栏专用的 `.archive-nav-rail` 重复按钮和 `openDestination` 可以删掉：每项都有自己的图标。
- **动效**：`grid-template-columns` 过渡 180ms，文字淡出 120ms；减少动态时直接切换。白片在 `transitionend` 时重新测位置（现有的 ResizeObserver 也会触发）。
- **行高三档**（桌面）：

  | 窗口高 | 导航行高 | 担当行 |
  |---|---|---|
  | > 880 | 40 | 52 |
  | 721–880 | 36 | 52 |
  | ≤ 720 | 32 | 44（头像 24，只留名字，「我的担当」进 `aria-label`），下接 8 |

- **还放不下时**（约 660 以下）：品牌行固定，担当行和导航一起滚动，把担当行放进滚动容器，条目就不会滑到它下面被切。滚动后顶边才出现 1px 细线。
- **图鉴**：
  - 侧栏只留一个入口（`Box` 图标），六类任意一类打开时它都是当前项。
  - 点开时去上次看的那一类（本机便利），没有记录就去道具。
  - 折叠格、`toggleFold`、`.archive-nav-cells` 都删掉。
- **组合**：`ARCHIVE_NAVIGATION` 加 `units`，排在偶像和卡片之间。图标要和偶像能分清，图标栏里只看得到图标。
- 原型实测（`shellfix.js` + `sidebarmock.js`）：图鉴一个入口，加上组合，1280×688 下 nav 溢出 0，「关于本站」底边在 672；1418×764 下溢出 0。

| 开关性质的复选框，例如「显示开放条件」、舞台设置 | GsSwitch。改变画面的放外层标题行，偏好进 GsRow |
